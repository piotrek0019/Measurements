# Data Measurements Platform  
### ASP.NET Core API • Vue.js Frontend • ML.NET • ClosedXML

This project is a full‑stack application designed to process, analyze, and visualize measurement data.  
It combines a modern **ASP.NET Core Web API** backend, a **Vue.js** frontend, **ML.NET** and **ClosedXML** for machine‑learning‑driven insights based on Excel datasets.

---

## 🚀 Features

### Backend (ASP.NET Core)
- RESTful API built with ASP.NET Core
- Endpoints for uploading and processing Excel datasets
- Data validation and transformation pipeline
- ML.NET integration for:
  - Regression
  - Classification
  - Anomaly detection (optional)
- Modular architecture ready for expansion

### Frontend (Vue.js)
- Modern Vue 3 SPA
- Interactive dashboards for measurement visualization
- Real‑time charts (e.g., Chart.js, ECharts)
- API integration with backend
- Clean component‑based structure

### Machine Learning (ML.NET)
- Automated data loading from Excel
- Training and evaluation pipelines
- Prediction endpoints exposed via API
- Extensible model architecture

### ClosedXML  (ML.NET)
Excel Data Access
- Strongly‑typed reading and writing of Excel files (.xlsx)
- Automatic detection of tables, ranges, rows, and columns
- Easy cell navigation with LINQ‑friendly APIs
- Support for formulas, formatting, styles, merged cells, and named ranges
